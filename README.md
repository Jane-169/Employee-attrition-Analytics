# Employee Attrition Analysis

## Overview
A Power BI dashboard exploring employee attrition patterns and workforce trends.

## Business Objective
To identify patterns in employee attrition and communicate findings through interactive data visualisations.

## Tools
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Key Metrics
- Total employees
- Number of Employees who left
- Attrition rate
- Attrition by age group
- Attrition by department
- Attrition by Gender
- Attrition by Job role
